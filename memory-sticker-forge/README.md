# memory-sticker-forge

**一张客户照片 → 6 枚可直接送切的水粉剪纸风格定制贴纸元素。**

一句话定位：**它不是一条 prompt，是一条带质检闭环的产线。**

---

## 为什么不是"给你一条 prompt"

生成模型有随机性，**没有任何 prompt 能保证 100% 成功** —— 谁这么说都是在骗你。

能做到的是**「用户侧一次成功」**：内部自己出图、自己体检、不合格自己定向重出，只把合格稿交出来。你敲一条命令，拿到的就是能送厂的文件。

实测：P1 一轮通过，P3 两轮通过（第一轮架子鼓支架过细，第二轮自动修好）。

---

## 用法

```bash
# 完整产线：体检 → 生成 → 质检 → 自动重试 → 交付
python3 forge.py 客户照片.jpg --outdir run_001

# 只做照片体检，不生成（不消耗生成额度）—— 用于免费"照片体检"引流话术
python3 forge.py 客户照片.jpg --preflight-only
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--elements` | 6 | 元素总数。**6 是 A5 全切的实际上限**，塞 7 枚必然挤 |
| `--max-rounds` | 4 | 最大重试轮数（v1.4 从 3 提到 4：排版失败已被消除，重试额度全部留给风格类问题） |
| `--preflight-only` | — | 只体检 |
| `--no-relayout` | — | 关掉程序化重排，回到「模型自己排版」的旧行为，仅用于对比 |
| `--gap` / `--margin` | 8 / 10 | 重排后强制的元素净距 / 四边留白 mm |
| `--figure-style` | `collage` | 人物画法。`collage`=分色剪纸拼贴（头发/皮肤/上衣/下装各一块平涂色纸，无脸）；`silhouette`=单色深色剪影 |
| `--dpi` | 400 | 重排后成品分辨率（148×210mm @400dpi = 2331×3307px） |

退出码：`0` 交付合格稿 ｜ `1` G0 拒稿（未花生成额度）｜ `2` 达到重试上限仍不合格，不交付

## 产线五步

```
① G0 照片体检 + 场景解析   ← 一次视觉调用，同时拿到光线/人数/IP/可提取物品清单
        ↓  不合格直接拒稿，不花生成额度
② 自动组装 prompt          ← 自动选色板、自动回填物品清单、自动回填 IP 剔除清单
        ↓
③ 4k 生成
        ↓
④ 程序化重排 (relayout.py)  ← v1.4 新增：抠出每枚元素，按网格重排到干净 A5
        ↓                     硬保证 邻距 ≥8mm、边距 ≥8mm，实测后才放行
⑤ 双重质检                 ← 量化(print-ready-doctor) + 目视(视觉模型 11 项)
        ↓  不合格 → 把失败项转成 prompt 补丁，回到 ②
⑥ 交付 FINAL.png + cutline.svg + qc_report.md
        ↓  凑满 4 单
⑦ A3 拼版 (impose_a3.py)   ← 4 张 A5 拼一张 A3，出 kiss cut + 全切 + 标记
```

### v1.4：排版为什么从 prompt 里拿走

LAYOUT 段落写得再狠（"gap 至少是较大元素宽度的三分之一"），模型也只是"倾向于"照做。
历史事故：目视看着分离得很开，量化一测邻距 **1.85mm** —— 白边一外扩就粘连，整版报废。

排版是纯几何问题，不该靠采样运气。现在出图后先过 `relayout.py`：
每枚元素连同原始像素抠出来，按 `cell = (板宽 - 2×margin - (列数-1)×gap) / 列数` 排进格子、
居中、只缩不放，**邻距 ≥ gap 由几何强制成立**，排完还要距离变换实测一遍才放行。

结果：量化质检里的三类失败（`邻距<3mm` / `必须修>0` / `元素数≠刀线数`）在物理上不再可能发生，
重试额度全部留给真正需要重生成的风格类问题（肤色、焦点色、物品数不足、可读文字）。

四张实测稿 relayout 前 → 后的最小邻距：6.36→12.11 / 7.99→11.75 / 9.56→11.06 / **3.27→9.33** mm。

**关键设计：第 ② 步的物品清单是从第 ① 步的照片解析里自动来的。** 这是「做成 skill」相对「写一条 prompt」的核心价值 —— prompt 里必须逐个点名这张照片里有什么物品，模型才不会把 6 枚全画成人物剪影。

## 元素配比（本产线最重要的一条规则）

```
6 枚 = 5 枚【纯物品】 + 1 枚【人物剪影】
```

纯物品 = 画面里只有单个物品，**没有人、没有场景背景、没有舞台、没有地面**。

**为什么物品占绝大多数：** 手账用户要的是能自由搭配的装饰件。人物剪影姿态固定、用途单一，多了反而重复（实测 4+2 配比时，两枚人物姿态明显重复）。

| | 纯物品 | 人物 |
|---|---|---|
| 原 skill（参照基准） | 5 枚 | 2 枚（共 7 枚） |
| 本产线 4+2 配比（已废弃） | 4 枚 | 2 枚 |
| **本产线 5+1 配比（当前）** | **5 枚** | **1 枚** |

并且要求物品**跨品类**（乐器 + 设备 + 灯光 + 家具 + 餐具），不能全是同一类。

## 双重质检：11 项目视 + 5 项量化

**目视（视觉模型，输出结构化 JSON）**

| 项 | 通过标准 |
|---|---|
| 纯物品枚数 | ≥5 枚 |
| 人物 | 完全无脸（无眼/眉/嘴/鼻/眼镜）。`collage` 档下允许且要求有皮肤色块与衣服配色；`silhouette` 档下要求单一深色、无任何肤色 |
| 黑描边 | 无 |
| 焦点色占比 | ≤15% |
| 剪纸边缘 | 暖白（米白），非纯白 |
| 质感 | 哑光水粉纸感 |
| 纤细结构 | 无 |
| 可读文字 / 品牌标识 | 无 |
| 物品贴纸内混入场景 | 无 |

**量化（print-ready-doctor）**

| 项 | 通过标准 | 为什么必须量化 |
|---|---|---|
| 有效分辨率 | **≥300 dpi** | 2k 出图在 A5 下只有 233 dpi，**屏幕上完全看不出来** |
| 必须修枚数 | = 0 | — |
| 元素数 = 刀线轮廓数 | 相等 | 不等即判定粘连 |
| 最小邻距 | **≥3mm** | 目视"完全分离"的稿子实测只有 1.85mm，**全切必报废** |

> ⚠️ **目视质检不能替代量化体检。** 实测有一版过了全部目视检查，量化一跑直接判死（邻距 1.85mm）。反过来量化也测不出"6 枚全是人物剪影"这种问题。**两者都必须跑。**

## 版权与合规（三层）

**第一层 · 风格自研**
本产线的 prompt 从零构建，不引用、不复制任何第三方 skill 的措辞或结构。额外包含三个原始 skill 不具备的模块：印刷可制造性、夜场色板、IP 剔除。

**第二层 · 第三方 IP 自动闭环**
```
G0 阶段自动检测 → 回填进 prompt 强制剔除 → 质检阶段复检"是否仍有可读文字或标识"
```
实测在 P3 演出照上检出 6 处（Orange / Dixon / Fender 三个乐器品牌标 + 舞台大屏内容 + 手机屏内容 + T恤图案），全部消除，成品零可读文字。

**第三层 · 肖像与授权**
- 人物**一律无脸**，显著降低肖像权与「画得像不像」争议（但不免除授权义务）
- G0 检出疑似未成年人时输出**人工确认警告**（不做硬阻断 —— 视觉模型在人群照上误报率高，真正的判断人是你）
- 下单前须取得客户书面授权，含"用于本单生产"与"是否同意案例展示"两项**分开勾选**

**第四层 · AIGC 标识（红线）**
产品页与说明卡必须标注「**AI 辅助生成 + 人工调整与手工裁剪**」。
🔴 **绝不使用「手绘」「手工绘制」「原创插画」** —— 这是硬红线，不是可以打擦边球的营销问题。

## 已知局限（诚实清单）

| 局限 | 说明 |
|---|---|
| **不能保证单轮通过** | 实测 P1 一轮、P3 两轮。**"100% 一次成功"在生成模型上不存在**，本产线保证的是"交出来的一定合格" |
| 每轮成本 | 1 次生成 + 1 次视觉质检。4 轮上限意味着最差消耗 4 倍 |
| 重排会缩小元素 | 网格是均匀的，一枚 60×82mm 的高瘦元素塞进 62×59mm 的格子会被缩到 72%。想要更大的成品件就得减少元素数（`--elements 4`） |
| 重排改变构图 | 输出是规整网格，模型原图那种错落感会消失。要原构图就用 `--no-relayout`，但邻距不再有保证 |
| `最细笔画` 指标失效 | print-ready-doctor 该项恒等于 2 像素（抗锯齿噪声），已知 bug，当前未纳入卡点 |
| 人数 >3 只警告不拦 | 多人照会把人物压成背景群像，可接单但需与客户说明 |
| 未成年人判定误报率高 | 只警告，需你人工确认 |
| 样本量小 | 累计仅 2 张照片走完全流程，稳定性结论不可外推 |

## 人物两档画法（v1.4 新增）

早期版本把人物写死成「单一深棕色剪影、禁止任何肤色」。这个约束当初是为了规避三件事：
AI 画脸容易画歪导致客户说「这不是我」、无脸不构成可识别肖像、大色块比精细面部更耐模切。

但它的代价是人物**没有皮肤色也没有衣服颜色**，在一版以物品为主的贴纸里显得突兀、发闷。
而且它其实**违背了风格本身** —— 水粉剪纸拼贴的做法就是多块彩色纸拼起来，不是一块黑影。

因此现在默认改为 `collage` 档：

| | `collage`（默认） | `silhouette` |
|---|---|---|
| 头发 | 一块深色 | 与全身同色 |
| 皮肤 | 一块风格化暖色（沙米/暖琥珀，非写实肤色） | 禁止出现 |
| 上衣 / 下装 | 两块不同的平涂палette色 | 与全身同色 |
| 五官 | 完全没有 | 完全没有 |
| 适用 | 默认。视觉丰富、仍无肖像争议 | 客户明确要求极简剪影，或人物在画面中很小 |

两档的 QC 判据是分开的：`collage` 档只卡「有没有五官」，不会因为出现肤色而判不合格；
`silhouette` 档才卡「有没有肤色」。**改档位必须同时改判据，否则会陷入无限重试。**

## 为什么四边留白默认是 10mm 而不是 8mm

留白的真实作用是抵抗「A3 切成 4 张 A5」这一刀的累积误差，误差链是：

| 环节 | 典型偏差 |
|---|---|
| 印刷图文位置 | ±0.3 ~ 0.5mm |
| 半切刀线光学对位 | ±0.5 ~ 1.0mm（低端设备可到 ±1.5mm） |
| A3 全切成 A5 | ±0.5 ~ 1.0mm |
| **最坏线性叠加** | **≈ 3.0mm** |

印刷业通用安全区是内容距成品边 ≥3mm。8mm 已经是它的 2.7 倍，本来就不会切到贴纸。
提到 10mm 的真实理由不是「怕切到」，而是**边距均匀度**：元素在格内居中，而元素宽度差异很大
（实测 30.5mm ~ 66mm），最宽的元素占满格子后边距恰好等于 margin，最窄的却能离边 20mm+，
同一列肉眼可见落差。把 margin 提到 10mm 后代价极小（元素仅再缩 2~3%，无需额外全局收缩，
k 仍为 1.000），换来到全切线 10.2mm 的余量和更稳的观感。

## 一张照片填满一整张 A3（`forge_a3.py`）

厂家一张 A3 = 20 元不限量，所以「单张照片能不能填满一张 A3」直接决定成本结构。

### 尺寸上完全够，这不是瓶颈

| 版面 | 网格 | 单枚格子 |
|---|---|---|
| A5 排 6 枚（现状） | 2×3 | 60.0 × 58.0 mm |
| A3 排 24 枚 | 4×6 | 63.25 × 60.0 mm |

A3 面积正好是 4 倍 A5，24 = 4×6，所以**单枚反而比现在大 9%，完全不缩水**。

### 但必须分 4 批生成，不能一次画 24 枚

| 做法 | 铺满 A3 的实际精度 |
|---|---|
| 单次 4k 出图（2352×3520）铺满 A3 | **201 dpi** ❌ 低于印刷底线 300 |
| 分 4 批各 4k、每批铺一张 A5、再拼 A3 | **404 dpi** ✅ |

除了分辨率，还有两个理由：6 枚都常需 2 轮才数对，一次要求 24 枚几乎不可能；
24 枚挤在一张生成图里，单枚有效像素只有 6 枚时的 1/4，细节直接崩。

### 真正的瓶颈是照片的信息量

`probe_capacity.py` 会把候选图案分四层报数：A 真实完整物品 / B 真实局部特写 /
C 同物变体 / D 通用装饰件。**只有 A+B 是「这张照片真正的信息量」。**

实测（加互斥纪律后的诚实值）：

| 照片 | 真实容量 | 瓶颈 |
|---|---|---|
| 生日餐厅（主体集中 + 背景虚焦） | **13 枚** | 前景物品少，背景重度虚化 |
| 故宫（建筑细节丰富） | **17 枚** | 单一建筑主体，栏杆/立柱等重复元素多 |

所以**一张普通照片撑不满 24 枚**。要真正填满需要信息量极大的照片：多人合影、市集、
房间全景、一次旅行的多个场景。

默认行为是**如实下调总数**（13 枚 → 3 批 5/4/4），不拿通用素材凑满；
需要凑满必须显式加 `--fill-generic`，且报告会提示这部分不是照片独有内容。

### 两个已修的重复陷阱

跑通第一版 19 枚时出现了 **3 枚几乎相同的甜点盘**，根因有两层：

1. **盘点层**：同一物理对象被拆成多项（`plate` 与 `plate rim pattern`；蛋糕/冰淇淋/蜡烛
   其实同处一盘却被列成三项）。→ probe 增加互斥纪律：同一物理对象只能出现一次，
   同处一容器的东西最多留最有辨识度的一项。这条纪律让该照片的报数从虚高的 19 降到诚实的 13。
2. **生成层**：4 批各自独立生成，模型不知道别批画了什么，会把「同处一盘」的组合反复整盘画出。
   → 新增 `--exclude`，把其它批次的清单作为排他约束写进 prompt，并明确要求
   「若你的物品通常放在被排除物之上，必须把它单独画出来，不要连着盘子/托架一起画」。

### 用法

```bash
python3 forge_a3.py 客户照片.jpg --outdir a3_run          # 盘点 → 分批 → 4 批生成 → 拼 A3
python3 forge_a3.py 客户照片.jpg --plan-only              # 只看这张照片能出多少枚、怎么分批
python3 forge_a3.py 客户照片.jpg --total 24 --fill-generic # 允许用通用件凑满（需告知客户）
python3 probe_capacity.py 客户照片.jpg --target 24         # 只做容量盘点
```

`--plan-only` 只花 1 次视觉调用、不消耗出图额度，**适合接单前先判断这张照片够不够本**。

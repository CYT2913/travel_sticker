# memory-sticker-forge

## 何时使用

| 场景 | 命令 |
|---|---|
| 客户下单后出稿 | `python3 forge.py <照片> --outdir run_<订单号>` |
| 客户问「我这张照片能做吗」（免费照片体检引流） | `python3 forge.py <照片> --preflight-only` |
| 需要 4 枚 / 8 枚等非默认数量 | 加 `--elements N`（**A5 全切上限是 6**） |

## 执行前必读

1. **先跑 `--preflight-only`。** 它不消耗生成额度，能提前判断这张照片值不值得做。G0 拒稿的照片直接回复客户换一张，别硬做。
2. **读 G0 的三类警告并人工判断：**
   - 疑似未成年人 → 需监护人书面授权（模型误报率高，必须你自己看照片确认）
   - 人数 >3 → 可接单，但要跟客户说明人物会被压成群像
   - 检出第三方 IP → 会自动剔除，但要确认客户不是专门为了那个 logo 才下单的
3. **不要跳过质检直接用 `round1.png`。** 只有 `FINAL.png` 是通过双重质检的稿子。
4. **送厂/送切用 `production/cutline.svg`**，并告知只切 `CutContour` 图层，**且刀线里已含 1.5mm 白边，请勿二次外扩、勿重新描轮廓**。

## 输出后必做

- 把 `qc_report.md` 存档，它是这一单的质量凭证
- 产品页与说明卡标注「AI 辅助生成 + 人工调整与手工裁剪」
- 🔴 **绝不宣称「手绘」「手工绘制」「原创插画」**

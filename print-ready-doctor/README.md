# print-ready-doctor

把 AI 生成的贴纸版设计稿，**体检 → 修复 → 重排 → 拼版 → 转成可直接送厂的生产文件**。

一句话价值：**它不是美化文件，是消灭返工。**

三个脚本，各管一段：

| 脚本 | 干什么 | 什么时候用 |
|---|---|---|
| `print_ready_doctor.py` | 单版模切体检 + 导出 `cutline.svg` | 任何时候想知道"这版能不能送厂" |
| `relayout.py` | **程序化重排**：把排版从"靠模型运气"改成"靠代码保证" | 模型出图之后、质检之前（forge.py 已内置） |
| `impose_a3.py` | **A3 四宫格拼版** + kiss cut + 全切线 + 裁切标记 | 凑满 4 个订单、要下单印刷时 |

典型生产流：

```
模型出图 → relayout.py（保证邻距/边距）→ print_ready_doctor.py（体检放行）
                                              ↓ 攒够 4 单
                                        impose_a3.py → 发工厂
```

# print_ready_doctor.py · 单版模切体检

## 为什么需要它

AI 生成的贴纸版，有三类问题在屏幕上完全看不出来，但送厂模切时会变成事故：

| 事故 | 表现 | 后果 |
|---|---|---|
| **A 断裂** | 面材太窄，刀一过就断 | 麦克风支架、鼓腿断掉 |
| **B 粘连** | 两枚贴纸挨太近，白边一外扩就连成一片 | 撕不开，整版报废 |
| **C 糊掉** | 白边把手指缝、鼓腿间隙桥接掉 | 手指并成"连指手套"，细节丢失 |

这三类都属于**「设计文件问题」——工厂不赔，而且一定延期。**
唯一的解法是在生成阶段就扫出来并修掉。

---

## 核心思路

模切走的不是图案轮廓，而是图案**外扩一圈白边后的刀线**。
所以修复动作不是改画面，而是**为每枚元素单独求解最优 offset**：

```
offset 太小  →  纤细处面材不够  →  断（A）
offset 太大  →  吃掉邻居间距    →  粘连（B）
             →  桥接内部缝隙    →  糊掉（C）
```

工具对每枚元素在可行区间内求解：

- 以 **1.5mm** 为目标白边（行业建议值，用来吸收模切位移误差）
- 邻居太近 → 往下压，但不低于 0.8mm；压不住就报**排版冲突**
- 纤细结构面材不够 → 往上加，直到跨过 1.5mm 安全线

## 安装

```bash
pip install -r requirements.txt
```

## 用法

```bash
# 完整体检 + 修复 + 导出生产文件
python3 print_ready_doctor.py sheet.png --sheet-width 148 --outdir out/

# 只体检，不导出
python3 print_ready_doctor.py sheet.png --sheet-width 148 --report-only
```

退出码：`0` = 可以送厂；`1` = 有必须修项或粘连，**不要送厂**。可直接用于流水线卡点。

### 主要参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--sheet-width` | 148 | 成品整版宽度 mm（A5 竖版宽=148） |
| `--safe-width` | 1.5 | 模切安全最小面材宽度 mm |
| `--offset-target` | 1.5 | 白边目标值 mm（行业建议 1.5~2） |
| `--offset-min` / `--offset-max` | 0.8 / 2.5 | 白边可调范围 |
| `--corner-radius` | 1.0 | 尖角圆角化半径 mm |
| `--min-area` | 25 | 忽略小于此面积的碎片 mm² |
| `--bridge-limit` | 2.0 | 内部缝隙糊掉比例告警线 % |

## 输出

| 文件 | 用途 |
|---|---|
| `report.md` | 人看的体检报告，含**风险排名 → 直接决定备损备哪枚** |
| `report.json` | 机读结果，可接流水线 |
| `preview_risk.png` | 风险标注预览（洋红=刀线，框色=风险等级） |
| `cutline.svg` | **生产文件**：原图 + `CutContour` 专色刀线，可用 Illustrator 打开 |
| `cutline_only.svg` | 纯刀版，部分工厂只要这个 |

SVG 的刀线在独立图层 `CutContour`，专色 100% Magenta，线宽 0.25pt ——
这是印厂通行规范，**告诉工厂"只切 CutContour 图层"即可**。

## 检查项清单

**印前**
- 有效分辨率是否 ≥300 dpi（按成品尺寸反算，不看文件标称 dpi）
- 色彩模式是否 CMYK（RGB 会提示交由工厂按其 ICC 转换）

**逐元素**
- 刀线最窄面材宽度 vs 安全线 → 断裂风险
- 到最近邻元素净距 vs 2×offset → 粘连风险
- 内部缝隙被桥接比例 → 细节丢失风险
- 图案最细笔画 vs 0.3mm → 印刷断线风险
- 锐角数量 → 切不干净、一撕就烂
- 离整版边缘距离 → 出血是否充足
- 元素面积 → 是否小到不易撕取

**全版**
- 元素数 vs 刀线轮廓数，不一致即判定粘连（**这一项是硬卡点**）

## 实测校准记录

在三张真实照片生成的贴纸版上校准（生日 / 车展 / 演出场景）：

- 分割参数定为 `close 0.7mm / 1 次迭代 / open 0.25mm`，三张均精确得到 **7 枚**元素，
  与独立视觉核对结果一致。
- `iterations` 必须是 1：用 2 会把间距近的元素糊成一块（实测 7 枚→2 枚）。
- 分割用**未去噪**掩膜，测量用**去噪**掩膜：去噪的开运算会切断元素与其投影的连接，
  把一枚元素拆成本体+投影两块（实测 7 枚→9/13/17 枚）。
- 邻居间距必须只用保留下来的元素计算，若用全部连通域会把已过滤的碎点当邻居，
  把间距误报成 0.1mm，虚报大量「排版冲突」。

三张实测结论：**无粘连、无必须修项**；共性问题是图案最细笔画普遍在
0.08~0.25mm，低于 0.3mm 印刷线宽下限，以及内部缝隙桥接率 7~22%。

---

## 已知局限

- 分割依赖「暖白纸底 + 彩色图案」的构图。换成深色底或满版出血的设计稿需重新校准阈值。
- 色差只做提示，**不做 ICC 校正** —— 这件事必须靠打样实物比对，软件替代不了。
- 输出 SVG 而非 AI/PDF。绝大多数印厂可直接接收或用 Illustrator 转存，
  若工厂坚持要 PDF，用 Illustrator 打开另存即可（不要用在线转换，会丢专色）。

# relayout.py · 程序化重排

## 为什么需要它

生成模型再怎么写 prompt，也只能"倾向于"把元素排开。实测踩过的坑：
**目视看着分离得很开，一测邻距只有 1.85mm** —— 白边一外扩就粘连，全切必报废。

排版是纯几何问题，代码能 100% 保证，不该交给采样运气。

## 做法

1. 复用 `segment_artwork()` 把每一枚元素连同原始像素抠出来
   （掩膜外扩 0.3mm + 羽化，暖白手切边和淡投影一起带走）
2. 在干净的 A5 白底画布上按网格重排：

```
cell_w = (板宽 - 2×margin - (列数-1)×gap) / 列数
cell_h = (板高 - 2×margin - (行数-1)×gap) / 行数
```

   每枚等比缩放到刚好塞进自己的格子并居中。
   格子之间本来就隔着 `gap`，元素又不出格 →
   **邻距 ≥ gap、边距 ≥ margin 在几何上被强制成立**。
3. 排完用距离变换**实测**邻距和边距再断言一次；万一不达标就整体缩 3% 重排，
   最多 8 轮，仍不达标则非零退出（绝不输出"看起来还行"的稿子）。

**不做的事**：不放大（只会等比缩小，放大 = 有效 dpi 下降 = 糊）、不旋转、不裁剪、不重绘。
像素原样搬运，风格 100% 保留。

## 用法

```bash
python3 relayout.py FINAL.png --outdir out/
python3 relayout.py FINAL.png --outdir out/ --gap 8 --margin 10 --dpi 400 --name p1b
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--in-width` | 148 | 输入图当作多宽 mm（用来换算元素的原始物理尺寸） |
| `--sheet-width` / `--sheet-height` | 148 / 210 | 输出画布尺寸 mm（A5 竖版） |
| `--dpi` | 400 | 输出分辨率。148×210mm @400dpi = 2331×3307px |
| `--gap` | 8 | **元素之间的最小净距 mm（硬保证）** |
| `--margin` | 10 | **四边最小留白 mm（硬保证）** |
| `--cols` | 0 | 强制列数，0 = 按元素数自适应（6 枚 → 2 列 × 3 行） |
| `--min-area` | 25 | 忽略小于此面积的碎片 mm² |
| `--name` | relayout | 输出文件名前缀 |
| `--no-verify` | — | 跳过 doctor 分割复验（省几秒） |

## 输出

| 文件 | 用途 |
|---|---|
| `relayout.png` | 干净的 A5 版，可直接进质检 / 拼版 |
| `relayout_report.txt` | 逐枚元素的最终尺寸 mm、缩放比、实测邻距、实测边距 |
| `relayout.json` | 同上，机读 |

## 实测（4 张真实稿，`--gap 8 --margin 10`）

| 稿件 | 重排前最小邻距 | 重排后最小邻距 | 重排后最小边距 |
|---|---:|---:|---:|
| run_p1b | 6.36 mm | **12.11 mm** | 8.00 mm |
| run_p3b | 7.99 mm | **11.75 mm** | 8.00 mm |
| run_gugong | 9.56 mm | **11.06 mm** | 8.00 mm |
| run_volunteer | **3.27 mm** | **9.33 mm** | 8.00 mm |

（重排后的数字取 doctor 自己分割出来的复验值，即工厂视角真值。）
四张重排后跑 `print_ready_doctor.py --report-only` 均为：
**必须修 0 枚 / 元素数 6 = 刀线轮廓数 6 / 无粘连**。

## 局限

- 网格是**均匀**的：一枚 60×82mm 的高瘦元素塞进 62×59mm 的格子会被缩到 72%。
  想要更大的成品件，只能减少元素数。
- 输出是规整网格，**模型原图那种错落构图会消失**。要保留原构图就别用它，
  但邻距就不再有保证。
- 元素分配按原图阅读顺序（先上下、后左右），不做美学上的大小平衡。
- **缩小会让细笔画一起变细**：缩到 72% 时，原本 0.4mm 的笔画会变成 0.29mm，
  可能跌破 0.3mm 印刷线宽下限。四张实测里细笔画告警总数反而从 9 条降到 4 条
  （INTER_AREA 下采样把毛刺抹平了），但这是运气不是保证 —— 重排后仍必须跑
  `print_ready_doctor.py` 复验，别跳过。
- 只认「白底 + 分离元素」的输入。满版出血稿、深色底稿会被 `segment_artwork()`
  分割成奇怪的东西，这是 doctor 的固有前提，relayout 只是继承了它。

# impose_a3.py · A3 四宫格拼版

## 为什么需要它

工厂只做 A3 不干胶数码印刷 + 模切，**一张 A3 = 20 元，数量多也不便宜**
（每单图案不复用，没有量产效应）。A3 = 297×420mm，正好放 4 张 A5（148.5×210mm）。
**把 4 个不同客户的稿子拼一张 A3，单客户成本直接除以 4。**

一张 A3 上要走两种刀：

| 刀 | 图层 | 作用 |
|---|---|---|
| kiss cut（半切） | `KissCut` · 100% Magenta · 0.25pt | 只切面材不切底纸，每张 A5 = 一整版可撕贴纸 |
| through cut（全切） | `ThroughCut` · 100% Cyan · 0.25pt | 把 A3 切成 4 张 A5，分别寄 4 个客户 |

## 对齐是怎么保证的（唯一重要的技术决定）

**不是先算刀线再拼版，而是先把 A3 位图拼完，再直接在这张位图的像素上分割、
求 offset、描轮廓。** 刀线坐标 = A3 像素 ÷ ppmm，中间没有任何一次坐标系变换，
所以位图和矢量错位在原理上不可能发生。

实测验证（把 SVG 的 KissCut 图层单独栅格化，与 `A3_print.png` 逐像素比对）：
刀线到图案的距离 **中位 1.52mm / p5 1.37mm / p95 1.65mm，落进图案内部的比例 0.0000%** ——
与设定的 1.5mm 白边目标一致。

## 用法

```bash
# 4 单拼一张 A3
python3 impose_a3.py a.png b.png c.png d.png --outdir a3_out/ \
        --order-labels ORD-01,ORD-02,ORD-03,ORD-04

# 只有 1~3 单也能拼，空位留白但仍画出该格裁切标记
python3 impose_a3.py a.png --outdir a3_out/ --order-labels ORD-01
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--dpi` | 400 | A3 输出分辨率（297×420mm @400dpi = 4677×6614px） |
| `--in-width` | 148 | 输入稿当作多宽 mm |
| `--order-labels` | — | 逗号分隔的订单号，按输入顺序对应；不填用文件名 |
| `--min-safe` | 5 | **任何贴纸离 A5 裁切线的最小距离 mm，不足自动内缩并在报告里标红** |
| `--bleed` | 0 | 额外出血 mm。默认 0：A3 定尺印刷，四周白底留白本身就是出血 |
| `--preview-dpi` | 120 | 预览图分辨率 |
| `--mark-len` / `--mark-offset` | 5 / 3 | 裁切角标线长 / 距裁切线距离 mm |
| `--safe-width` `--offset-min` `--offset-target` `--offset-max` `--corner-radius` `--min-area` | 同 doctor | 直接透传给 `solve_offset()`，**不要随便改，那些是校准过的** |
| `--no-embedded` | — | 不生成 base64 内嵌版 SVG（内嵌版 400dpi 下约 22MB） |

## 输出

| 文件 | 给谁 | 说明 |
|---|---|---|
| `A3_print.png` | 只要图片的工厂 | 297×420mm 满版图案，**不含任何刀线和标记** |
| `A3_production.svg` | 要 SVG 的工厂 | 分层矢量，`xlink:href="A3_print.png"` 相对引用，需与 PNG 同目录 |
| `A3_production_embedded.svg` | 同上（防丢图） | 位图 base64 内嵌，单文件即可 |
| `A3_preview.png` | 自己核对 | 图案 + 洋红半切 + 青色全切 + 角标 + 5mm 安全线 + 逐格数据 |
| `imposition_report.md` | 自己存档 | 每格订单号/元素数/最小邻距/离裁切线距离 + 下单说明 |
| `厂家须知.txt` | 直接发工厂 | 可整段复制的下单说明 |

SVG 单位是 mm（`width="297mm" height="420mm" viewBox="0 0 297 420"`），
工厂打开就是实际尺寸，不用再问"这个文件多大"。

图层：`Artwork` / `KissCut` / `ThroughCut` / `TrimMarks` / `Registration`。

## 裁切标记的一个诚实说明

4 个 A5 在 A3 上是**紧密相邻、没有中缝**的，所以传统"向外伸出"的 crop mark
必然伸进邻格画面。本工具把角标做成**向内偏移 3mm 的 L 形角括号**：
角标上的点离裁切线恒为 3mm，而拼版强制任何贴纸离裁切线 ≥5mm，所以角标永远压不到画面。
**裁切请以 `ThroughCut` 的矢量线为准，角标只作对位参考** —— 这一条已写进 `厂家须知.txt`。

## 局限

- **A5 单张成品实际是 148.5×210mm**（A3 的 1/4），不是标准 A5 的 148×210。
  相差 0.5mm，稿子居中放，两侧各多 0.25mm 白边，肉眼无感。
- 4 个格子的位置固定按输入顺序，不做装箱优化（每格都是整张 A5，也没什么好优化的）。
- 只支持 2×2 A5。要拼 8 张 A6 之类的排布得改 `A5_W/A5_H/cells` 三个常量。
- **没有做 CMYK 转换、没有嵌 ICC**。文件是 RGB，转 CMYK 必须由工厂按其设备特性文件做
  —— 这件事软件替代不了，只能靠打样比对。
- 生成一张 4 格 400dpi 的 A3 约 30 秒，内嵌版 SVG 约 22MB（微信可能发不了，用网盘）。
